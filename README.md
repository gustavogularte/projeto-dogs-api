# 📖 Sobre

O **Dogs API** é o backend utilizado pela aplicação **Dogs**, uma rede social para cachorros desenvolvida durante o curso **React Completo** da Origamid.

A API foi construída utilizando **WordPress** e sua **REST API**, sendo responsável pelo gerenciamento dos dados da aplicação, autenticação de usuários e comunicação com o Front-end desenvolvido em React.

---

# ✨ Funcionalidades

A API fornece recursos para:

- 👤 Cadastro de usuários
- 🔐 Autenticação e login
- 🔑 Recuperação de senha
- 🐶 Cadastro de publicações
- 📸 Upload de imagens
- 💬 Gerenciamento de comentários
- ❤️ Listagem de publicações
- 👤 Dados do perfil dos usuários
- 🔄 Comunicação via REST API

# 🎯 Objetivo

Este repositório tem como objetivo disponibilizar a API utilizada pela aplicação **Dogs**, permitindo a integração entre o Front-end desenvolvido em React e o backend baseado em WordPress.

Além de servir como suporte para a aplicação, o projeto proporcionou uma melhor compreensão sobre autenticação, consumo de APIs REST e integração entre Front-end e Back-end.
